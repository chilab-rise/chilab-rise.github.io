Security built into the wireless hardware

Wireless physical-layer security uses the behavior of circuits and antenna arrays to provide security functions directly in the radio. In collaboration with Prof. Kaiyuan Yang’s group, we explore low-overhead methods suited to resource-constrained devices.

One direction uses PUF-controlled transmitter spectral regrowth for device identification. Another uses antenna subset modulation and frequency-diverse sub-arrays to resist wireless eavesdropping. These complementary primitives address identification and communication security through different mechanisms.
